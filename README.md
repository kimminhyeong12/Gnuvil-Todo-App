# Gnuvil Todo App

React와 Spring Boot로 만든 로그인 기반 Todo 애플리케이션입니다.  
사용자는 회원가입/로그인 후 본인의 할 일을 추가, 수정, 완료 처리, 삭제할 수 있습니다.

## 배포 주소

- Frontend: https://gnuvil-todo-app.vercel.app
- Backend: https://gnuvil-todo-app.onrender.com

## 기술 스택

### Frontend
- React
- TypeScript
- Vite
- TanStack Query
- Axios
- Tailwind CSS

### Backend
- Java 17
- Spring Boot
- Spring Web
- Spring JPA
- Spring Security
- PostgreSQL

- ### Deploy
- Vercel
- Render
- Supabase PostgreSQL

## 주요 기능

- 회원가입
- 로그인
- 로그아웃
- 로그인한 사용자별 Todo 조회
- Todo 추가
- Todo 수정
- Todo 완료 상태 토글
- Todo 삭제
